How it works

Same pattern as the popular README stat trackers — a dynamic SVG endpoint.

  1. You enter a username We query GitHub for commits, PRs, merged work, issues, reviews, streaks, and languages.
  2. SVG cards are rendered on demand GitHub’s README renderer loads the image URL; our API returns a fresh SVG.
  3. One markdown line embeds it forever Change themes or options with query params — no rebuild, no commit of binaries.
